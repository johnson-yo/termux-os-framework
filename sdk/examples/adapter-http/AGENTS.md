# Example Package instructions

This is a testable SDK example, not a production adapter. Use only a local fixture endpoint and
never add a credential value, vendor SDK, or device address to source. The blank
`data-provider-credential` field demonstrates the external-provider boundary: Browser Session
submission, private backend persistence, masked reads, and no browser storage.

Keep the Package page under the Admin Adapters group and use the shared Browser
Session for same-origin Framework APIs.

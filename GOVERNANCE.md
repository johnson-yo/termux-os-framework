# Governance

The project is maintainer-led.

Maintainers are responsible for Core scope, public contracts, security releases, licensing, and repository access. Contributors propose changes through review. Decisions favor, in order:

1. user safety and data integrity;
2. a replaceable and vendor-neutral Core boundary;
3. backward-compatible public contracts;
4. the smallest implementation that is operationally reliable.

Changes to authentication, storage boundaries, Package identity, release verification, or licensing require explicit maintainer review. Extension Package maintainers control their own implementation and license as long as they satisfy the published Framework contracts.

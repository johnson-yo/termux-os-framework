# Public history

Framework began inside a larger product workspace and accumulated product services, hardware adapters, model assets, device deployment scripts, and experimental reports in the same tree.

The independence pass established one public truth:

- Framework Core became its own Git repository.
- Product, service, adapter, and asset source became independent local repositories with preserved component history.
- Bundled Package source and product-specific audio, ASR, translation, TTS, model, and device behavior were removed from Core.
- Public configuration became device-neutral and secret-free.
- Core adopted Apache-2.0 and English public documentation.

Detailed device experiments and private operational evidence are intentionally not part of the public Core repository.

# Support

Before requesting help:

```sh
npm test
npm run check:public
./sdk/termux-os-sdk doctor <package-id>
```

For Framework problems, provide the Core version, operating system, Node.js version, the failing command, and sanitized logs. For engine, model, audio, device-adapter, or application behavior, use the responsible Extension Package's support channel.

Do not publish credentials, private network addresses, local usernames, device identifiers, private audio, or model license files.
